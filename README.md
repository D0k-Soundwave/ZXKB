# ZXKB

Lightweight RGB lighting controller for QMK keyboards, born on a Keychron Q3 dressed in ZX Spectrum keycaps.

- Tray app for Windows: effects, audio VU meter (including an AY-style A/C/B channel mode), profiles and hotkeys
- QMK firmware with ZX Spectrum effects and live colour calibration
- Work in progress: see `docs/REQUIREMENTS.md`
